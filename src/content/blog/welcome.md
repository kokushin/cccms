## ようこそ

Claude Code on the webで管理する静的ブログシステムへようこそ！

このブログは、AstroとGitHub Pagesを使って構築されています。Claude Codeを対話型CMSとして活用することで、コマンドベースで記事の作成・編集・削除が可能です。

## 特徴

- **シンプルな構成**: Astroを使った高速な静的サイト生成
- **対話型CMS**: Claude Code on the webで記事を管理
- **GitHub Pages**: 無料でホスティング
- **Markdownベース**: 記事はすべてMarkdown形式で管理

## 使い方

`CLAUDE.md`に記載されているコマンドを使って、記事の作成・編集・削除が簡単に行えます。

詳しくは、プロジェクトルートの`CLAUDE.md`をご覧ください。
